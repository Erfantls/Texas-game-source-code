Texas Holdem Poker Source Code

A Unity client and C++ game-server solution for real-time multiplayer poker products, including clubs, private tables, alliances, MTT, SNG, MySQL and Redis.

Core capabilities

  • Unity and C# clients for iOS and Android
  • C++ rooms, hand state, betting, settlement and real-time messaging
  • Poker clubs, alliances, friend games and private tables
  • Multi-table tournaments and sit-and-go events
  • MySQL persistence with Redis cache and sessions
